# ADR-058: S14 -- «О телефоне», номер сборки впервые появляется в проекте

## Статус

Принято, 2026-09-13.

## Контекст

Пользователь запросил спроектировать и реализовать полный набор
недостающих системных функций (S14-S25), с физической проверкой на
устройстве одним финальным шагом в конце всей серии (`/goal`), а не
после каждого спринта, как во всех предыдущих 13 спринтах проекта.
Это ADR фиксирует это отступление явно: каждый ADR серии S14-S25
отмечает Device-раздел как "отложено", без нарушения общего принципа
"физически проверено, а не предположено" -- проверка просто
переносится в конец, не отменяется.

Никакого понятия "номер сборки" в проекте не существовало вообще --
ни git-хеша, ни version-файла, нигде.

## Решение

`build.rs` вживляет `git rev-parse --short=12 HEAD` в бинарь через
`SAAIOS_BUILD_ID` на этапе компиляции. `crates/system-tools`
сознательно не переиспользован -- слишком тяжёлые зависимости
(`tokio`/`async_trait`) для добавления в `saai-shell`.

## Test

Host: тесты и clippy чисты, кросс-компиляция под `pixel7` чиста.
Device: отложено (см. Контекст) -- будет частью общего финального
прохода по всей серии S14-S25.
