# ADR-430: Orb — непрерывное пространство навигации

## Статус

Принято, 2026-10-01. Host-код и тесты; на панели Pixel 7 не смотрели
(end-of-queue hardware pass). Заменяет роль Orb как точки + радиального
меню из HIA v2 §8–12 и роль Orb-хоста из ADR-116. Уточняет ADR-429.

## Контекст

Владелец предоставил Design Brief: Orb — не лаунчер и не радиальное меню, а
непрерывная пространственная география; экран — viewport. Прежняя
реализация (точка справа вверху + радиальное меню действий) этой модели
противоречила.

## Решение

1. Новый чистый crate `crates/saai-orb` (без IO): геометрия на сфере,
   камера/проекция, география с квантованием, компоновка по ярусам,
   навигационный ввод, жесты, поиск с маршрутом, доступность.
2. Шелл (`services/saai-shell`) получает `orb_space` (состояние, активации,
   сохранение географии в `/data/saaios/var/orb-geography.json`) и
   `render/orb_paint` (CPU-канвас, opaque-first).
3. В покое — купол над нижней навигацией; подъём непрерывный; отдельного
   экрана нет. Орб первым claim-ит касания, нижняя навигация работает.
4. Контекст меняет заметность, не позицию. Задачи — эфемерные подсказки
   (≤6). Недоступное остаётся призраком.
5. Старый код удалён: `OrbAction`, `orb_menu_actions`, `orb_view`,
   `draw_orb`, `draw_quantity_arc`, `Canvas::arc`. Прежние действия
   доступны как объекты E1/E2 (Входящие, Sai, Устройства/Bluetooth).
6. Шкала количества (ADR-429) переехала с полной точки на открытый обод
   купола (`arc_span`, слева направо, цвет Border, без severity).
   `Canvas::arc` из ADR-429 заменён.
7. `saai_ui_compiler::v2_orb_zone_rect` / `v2_orb_dot_size` шеллом больше не
   используются.

## Последствия

- Orb работает без AI и сети; Sai — лишь одно из мест в пространстве.
- Позиции стабильны между запусками (пространственная память).
- ORB-03..05 (поиск, ввод и доступность, забыть и перф) выполнены на host;
  см. ORB-ROADMAP. Шелл теперь привязывает `wl_pointer`, но только для
  сферы (ADR-012 остаётся в силе для остального UI).
- Не сделано: чтение осей геймпада, масштаб колесом, прокрутка списка пальцем.
- Риски (проверить на железе): частота кадров при pan, перекрытие нижнего
  контента куполом, размеры целей касания, контраст купола и шкалы.
- Rollback: вернуть коммиты шелла до ADR-430; crate можно оставить.
