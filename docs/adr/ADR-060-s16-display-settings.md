# ADR-060: S16 -- яркость и таймауты, первая система персистентных настроек

## Статус

Принято, 2026-09-13.

## Контекст

Яркость экрана никогда не читалась/не писалась из нового Wayland-
стека -- реальный sysfs-путь (`.../panel0-backlight/brightness`,
диапазон 0-4095) был известен только старому C boot/recovery UI
(`drm-splash.c`, только чтение). Таймауты блокировки/сна были либо
жёстко заданной константой (`IDLE_TIMEOUT`), либо настраиваемым только
через env var при старте процесса (`deep_idle_timeout`, S11) -- ни то,
ни другое не может быть изменено самим работающим шеллом.

## Решение

`ShellSettings` -- первый персистентный, пользователем изменяемый
конфиг в проекте: один плоский JSON-файл
(`/data/saaios/var/shell-settings.json`), без `serde`-derive (только
`serde_json::Value`, уже зависимость, тем же способом, что и
свойства задач в этом файле). Три поля: `brightness_pct`,
`idle_timeout_secs`, `deep_idle_timeout_secs`.

Взаимодействие -- тап-по-циклу через 4 дискретных значения
(`next_in_cycle`), а не drag-слайдер: в этом UI вообще нет
жест-рендеринга, все существующие взаимодействия -- тап по карточке.
`SAAIOS_DEEP_IDLE_SECS` (S11) остаётся живым как приоритетный над
файлом override для физического тестирования.

Три новые карточки на "Я" (индексы 3-5, после сводки/сборки/
хранилища из S14/S15) со своим hit-test'ом (`me_action_at`) --
"Входящие"/"Сейчас" уже установили паттерн "своя раскладка + свой
hit-test для страницы с контентом, которого нет в `root.sui`", здесь
он впервые применён к ФИКСИРОВАННОМУ (не рантайм-переменному) набору
строк.

## Test

Host: тесты/clippy чисты, кросс-компиляция под `pixel7` чиста.
Device: отложено (ADR-058).
