# ADR-055: S13 Change 3 -- "Я" из реальной сводки устройства и приложений

## Статус

Принято, 2026-09-13.

## Контекст

Как и "Входящие" до ADR-054, "Я" не имела записей в `root.sui` --
всегда серые placeholder-строки. У клиента уже были все данные,
нужные для честного содержимого: `spaces`/`entity_counts` (для
вкладки "Пространства") и `apps_by_pid`/`apps_grants` (для portal
авторизации) -- но ни то, ни другое не хранило достаточно для показа
(имя приложения, версия, состояние, полный список приложений
независимо от того, запущены ли они прямо сейчас).

## Решение

- Новое поле `installed_apps: BTreeMap<String, AppSummary>` --
  третий кэш рядом с `apps_by_pid`/`apps_grants`, заполняется тем же
  `note_app_summary()`, очищается на `List`-ответе, удаляется на
  `Removed`-событии -- тот же паттерн, что уже был для двух других
  кэшей.
- `app_state_label()` переводит уже существующий словарь
  `saai-appd`'s состояний (`running`/`stopped`/`crash_limited`/
  `installed`) тем же способом, что `capability_label` уже переводит
  capability-имена -- включая тот же fallback на исходную строку для
  нераспознанного значения.
- `me_content_cards()`: первая карточка -- сводка ("Пространств: N ·
  Объектов: M" из уже трекаемых `spaces`/`entity_counts`), затем одна
  карточка на каждое установленное приложение (имя, состояние,
  список выданных разрешений через уже существующий
  `capability_label`).
- `stacked_row_rect` (переименован из `inbox_row_rect`, ADR-054) --
  теперь общая раскладка для любой страницы с рантайм-определяемым
  числом карточек, используется и "Входящими", и "Я".
- Только для чтения -- у `saai-app-protocol` нет запроса на отзыв
  одной конкретной capability у уже согласованного приложения (только
  `DecideConsent`, всё-или-ничего при установке), так что тапу по
  карточке приложения нечего делать; явно вне скоупа DoR.

## Test

Host: `cargo test -p saai-shell` -- 22/22 зелёные. `cargo clippy -p
saai-shell` чист. Кросс-компиляция чиста, hash
`f5ab66154fa3efab5c4c9035d3e95165e1aa2fd0d3ca308e58b378f85b16a6b6`.

Device (`cp && mv` + `chmod`, ADR-042): физически подтверждено --
пользователь увидел сводку устройства (пространства/объекты) и
список приложений с разрешениями на вкладке "Я" сразу после
разворачивания.

## Последствия

- `installed_apps` дублирует часть данных из `apps_grants` (те же
  `granted_capabilities`) -- сознательный выбор вместо рефакторинга
  трёх кэшей в один, чтобы не трогать уже физически проверенный
  `update_app_caches`/`note_app_summary`/portal-путь больше
  необходимого для этого Change.
