# ADR-070: build-native-c-image.sh still bundled Inter, not Montserrat

## Статус

Принято, 2026-09-13.

## Контекст

Готовя первый физический прогон серии S14-S25, потребовалось
пересобрать полный `init_boot` образ (`build-native-c-image.sh`) --
до этого момента с S13 Change 5 (ADR-057, смена шрифта на
Montserrat) прошло много спринтов, ни один из которых не трогал
этот скрипт. Сборка образа показала: `os/targets/panther/assets/
fonts/` всё ещё содержал `Inter-{Regular,SemiBold}.ttf` и общий
`OFL-1.1.txt`, и `build-native-c-image.sh` бандлил именно их в
`/saaios/fonts/` -- при этом `render::Fonts::load_system()` (с
S13 Change 5) читает `/saaios/fonts/Montserrat-{Regular,SemiBold}.ttf`.

Если бы образ был прошит как есть, `Fonts::load_system()` вернула бы
`Err` (файлы с этими именами отсутствуют), `self.fonts` стала бы
`None`, и КАЖДАЯ функция отрисовки в `render.rs` ушла бы в свой
no-font fallback (голые прямоугольники без единой буквы) -- то есть
весь текст интерфейса исчез бы полностью, не просто "не тот шрифт".

Причина расхождения: font-swap в S13 Change 5, судя по всему,
проверялся на устройстве через прямую заливку файлов в уже
работающую систему (сами `.ttf` для растрового рендеринга нашлись в
`/tmp/Montserrat-*.ttf` на build-сервере), а не через пересборку
этого образа -- сам скрипт с тех пор ни разу не пересобирался и
не был обновлён вслед за тем решением.

## Решение

- `Montserrat-{Regular,SemiBold}.ttf` и `Montserrat-OFL.txt`
  (найдены на build-сервере в `/tmp`, размер `Montserrat-Regular.ttf`
  -- 374500 байт, совпадает с байт-в-байт подтверждением из S13
  Change 5) скопированы в `os/targets/panther/assets/fonts/`.
- Старые `Inter-{Regular,SemiBold}.ttf`/`OFL-1.1.txt` удалены оттуда
  -- не используются нигде с S13 Change 5.
- `build-native-c-image.sh`'s три строки `add ... saaios/fonts/...`
  переписаны на `Montserrat-*` имена.
- Полный образ пересобран (`dist/panther/saaios-panther-init_boot.img`,
  ровно 8388608 байт, `SOURCE_COMMIT f08e8f0`) и подтверждён
  содержащим правильные файлы шрифтов перед прошивкой.

## Test

Пересборка образа прошла чисто, итоговый размер образа не изменился
(8388608 байт, тот же фиксированный размер, который проверяет
`flash-s01-evidence.sh`) несмотря на то, что Montserrat-файлы почти
впятеро больше Inter -- запас в ramdisk был. Реальная проверка (что
текст физически отображается после прошивки) -- часть текущего
консолидированного физического прохода по S14-S25, не отдельный шаг.

## Последствия

- Открытый процессный урок: любое ADR, меняющее что-то в `/saaios/`
  на уже работающем устройстве напрямую (не через этот скрипт),
  должно в тот же спринт обновлять и `build-native-c-image.sh` --
  иначе следующая полная пересборка образа тихо откатывает это
  изменение. Ни ADR-057 (шрифт), ни какой-либо более поздний ADR
  этого не сделали для шрифта; стоит перепроверить, нет ли других
  таких же расхождений между "что реально на устройстве сейчас" и
  "что произведёт свежая пересборка этого скрипта" перед следующим
  полным reflash.
