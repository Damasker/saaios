# ADR-512: current-slice deferral is not a permanent ban

## Статус

Принято, 2026-10-12. Docs only. No binary flash. Lock marker stays.
Public `Damasker/saaios` `main` is not the source of truth for this
path; PIXEL-PATH / VUI-09 / ADR-232 / `saai-taskd` live on
`pixel-7-main`.

## Нумерация

После ADR-511 следующий свободный номер — **512**. Не S33. Не 426
(занят на `wip/hdi-lab`).

## Контекст

Отказ от роя и от повторного включения lock в текущем срезе принят.
Риск второго оркестратора и проприетарный Claude Code dump остаются
основаниями не портировать coordinator / swarm mailbox / autoDream
как код. Это не доказательство, что рой «ломает модель», и не
обобщение, что любой Oracle раздаёт власть.

`PolicyVerdict::{Allow, AskUser, Deny}` существует в дереве. Это ещё
не доказательство, что каждый путь исполнения на Pixel проходит
через Policy. Покрытие — отдельная проверка маршрута вызова.

Lock SIGTRAP после первого lock-кадра записан в ADR-503/510 как
открытый дефект рабочего дерева. Независимое подтверждение по
логам публичного `main` отсутствует. Пока нет воспроизведения —
маркер `/run/saaios/dev-no-lock` не снимать.

Самоорганизующаяся система (ATTN/WORK, накопление опыта, Advisor,
будущее распределённое исполнение) этим срезом не отменяется.

## Решение

1. **Текущий срез.** Не внедрять рой, новый координатор, `agentd`
   и не поднимать lock. Продолжать ATTN/WORK на существующих
   контрактах. `dest-no-lock` не трогать.
2. **Не навсегда.** Пункт 1 — очередь, не архитектурный запрет.
   Рой / Advisor / распределённое исполнение остаются возможными
   после отдельной спецификации.
3. **Lock.** Отдельный дефект: воспроизводимый SIGTRAP, причина,
   восстановление после смерти lock-клиента, повторный unlock.
   До закрытия — не Acceptance VUI-09 и не снятие маркера.
4. **Oracle.** Будущий консультативный API поверх runtime / ATTN /
   Observation. Без власти над `policy-engine`. Без второго
   оркестратора.
5. **Policy.** Не утверждать полную защиту всех путей на Pixel,
   пока нет интеграционного маршрута tool → Policy → execute.

## Откат

Удалить этот ADR. Очередь среза не меняется.
