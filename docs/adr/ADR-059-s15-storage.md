# ADR-059: S15 -- использование хранилища на "Я"

## Статус

Принято, 2026-09-13.

## Контекст

Ни статвфс-чтения, ни любого другого способа узнать занятое место на
диске в проекте не было. `std` не даёт кросс-платформенного API для
этого; в файле уже есть прецедент (`current_time_string`, S13) --
шеллиться в маленькую системную утилиту вместо новой зависимости ради
одного нечастого чтения.

## Решение

`storage_usage_kb()` шеллится в `df -k /data` и парсит колонки
`1K-blocks`/`Used` из второй строки вывода -- `/data`, а не корень,
потому что это раздел, на котором реально живут пользовательские
данные и приложения (`--data-root`, S05), а не read-only системный
образ. Третья карточка на "Я": "Хранилище" / "X.X ГБ из Y.Y ГБ
занято".

## Test

Host: тесты/clippy чисты, кросс-компиляция под `pixel7` чиста.
Device: отложено, см. ADR-058 (общий финальный проход по S14-S25).
