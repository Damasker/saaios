# ADR-057: S13 Change 5 -- визуальный проход (карточки, шрифт), спринт закрыт

## Статус

Принято, 2026-09-13. Спринт S13 закрыт.

## Контекст

После физической проверки Changes 1-4 пользователь прямо оценил
результат как визуально сырой: (1) информационные карточки
("Это устройство" на "Я", пустое состояние "Входящих") выглядели
кликабельными -- показывали ту же иконку-плашку и акцентную "кнопку"
цвет, что и настоящие интерактивные карточки; (2) шрифт Inter не
понравился. Отдельно поднятый запрос на сетку/иконки в духе home
screen Android признан отдельной, существенно большей по объёму
задачей и сознательно вынесен за пределы этого Change (см.
Последствия).

## Решение

**Карточки.** `render::draw_root`'s цикл отрисовки карточек теперь
проверяет `card.action.is_empty()`: для таких карточек не рисуется ни
акцентная иконка слева, ни акцентная кнопка справа -- только
заголовок и статус, начинающиеся от левого края (а не после места под
иконку). Интерактивные карточки (с непустым `action`) отрисовываются
как прежде, без изменений.

**Шрифт.** Заменён с Inter на Montserrat -- после физически
подтверждённой (не гипотетической) серии попыток:

1. Manrope -- технически загрузился и использовался (подтверждено),
   но физически оказался визуально неотличим от Inter на реальном
   экране при используемых размерах текста.
2. Space Grotesk и Sora -- рассмотрены и отклонены ДО развёртывания:
   ни один не содержит ни одного глифа кириллицы (проверено
   `fontTools`'s `cmap`), что сломало бы весь русскоязычный интерфейс
   целиком.
3. Montserrat -- выбран, содержит полный набор кириллицы (проверено
   тем же способом), физически развёрнут.

Ни Manrope, ни Montserrat, ни Space Grotesk/Sora/Unbounded/Jost/
Outfit/Syne не имеют статичных per-weight файлов в репозитории Google
Fonts (все давно переведены на variable-only формат) -- `fontdue` не
поддерживает variable font axes вообще (проверено по исходникам
крейта: ни одного упоминания `fvar`/`wght`/variation). Нужные
статичные инстансы (Regular=400, SemiBold=600) сгенерированы
`fonttools varLib.instancer` на build-сервере (venv, `pip install
fonttools`) из variable-файла каждого кандидата.

## Test

Host: `cargo test -p saai-shell` -- 22/22 зелёные, ни один тест не
менял поведение (нет тестов, специфичных для конкретного шрифта или
визуального вида карточки). `cargo clippy -p saai-shell` чист.
Кросс-компиляция чиста, финальный hash
`32762ac1bfa5bd7a39061f6921c279a91c8307d512bda0f7d7a8261aa2dd0dce`.

Host, отдельно (вне `saai-shell`'s тестов): временный throwaway-бинарь
подтвердил, что `fontdue::Font::from_bytes` корректно парсит и
растеризует оба сгенерированных статичных файла (включая кириллический
символ явно, для Montserrat) до развёртывания на устройство.

Device (`cp && mv` + `chmod`, ADR-042):

- Карточки без действия физически подтверждены пользователем как
  переставшие выглядеть кликабельными.
- Шрифт: физически подтверждено через временную диагностику
  (`eprintln` точного размера в байтах загруженных файлов), что
  Montserrat-Regular.ttf (374500 байт) и Montserrat-SemiBold.ttf
  (374624 байта) -- точное совпадение с реальными файлами на диске --
  действительно то, что оказывается в `Fonts.regular`/`Fonts.
  semibold`. Диагностика убрана перед финальной сборкой (совпадает по
  hash с уже собранной "чистой" версией -- добавление и удаление
  идентичных строк дало байт-в-байт тот же бинарь).

**Честный остаток.** Несмотря на технически подтверждённую загрузку
корректного, визуально отличного от Inter файла, пользователь дважды
(для Manrope и снова после переключения на Montserrat) сообщил, что
не воспринимает разницу на реальном экране. Причина не установлена --
не исключены: типичный для простых grayscale-рэстеризаторов вроде
`fontdue` (без hinting) эффект нивелирования различий между
геометрическими гротесками на малых кеглях; условия просмотра;
величина субъективного порога. Дальнейшее расследование не
проводилось по совместному решению с пользователем -- закрыто с
Montserrat как технически корректным, финальным выбором.

## Последствия

- Сетка/иконки в духе home screen -- явно вне скоупа этого Change и
  всего S13; при обсуждении признано отдельной, существенно большей
  задачей (нет ни одной готовой иконки, ни сеточной system разметки
  ни для одной из 4 вкладок) -- кандидат на будущий отдельный спринт
  со своим Definition of Ready.
- Файлы `/saaios/fonts/Inter-*.ttf`, `OFL-1.1.txt` и промежуточные
  `Manrope-*.ttf` удалены с устройства при развёртывании Montserrat --
  сами файлы никогда не были частью git-репозитория (шрифты всегда
  жили только на устройстве/в образе, не в исходниках), поэтому в
  diff'е этого ADR фигурируют только пути в коде, не сами файлы.

## Паспорт S13 -- Done

Все 5 Changes физически подтверждены (ADR-053..057). Спринт закрывается
`Done` с честными оговорками: `saai-taskd` не развёрнут на тестовом
устройстве (Change 2's остаток), экстремальный субъективный порог
восприятия шрифта не объяснён технически (Change 5's остаток).
Backend-протоколы не менялись ни в одном Change.
