# SaaiOS Orb v1 — спецификация пространственной навигации

Источник: Design Brief & Interaction Specification (концепт владельца,
2026-10-01). Решение: [ADR-430](../../adr/ADR-430-orb-spatial-navigation.md).
План: [ORB-ROADMAP](../sprints/ORB-ROADMAP.md).

Главная формула: **экран — это окно (viewport), Orb — география.**

## 1. Что это и чем не является

Orb — непрерывное пространство навигации. Огромная сфера; экран показывает
её фрагмент. Это не лаунчер, не радиальное меню, не плавающая AI-кнопка, не
декоративная 3D-сфера и не карусель. Отдельного «экрана Orb» нет.

Окна и приложения остаются. Sai может участвовать, но Orb работает без AI:
вращение, зум, выбор и локальный поиск — локальные операции.

## 2. Покой и подъём

В покое видна только малая «точка» (купол) над нижней навигацией. Точка
поднимается непрерывно (pull → commit при 0.35 пути или скорости 700 units/s),
без переключения экранов. Сфера вырастает геометрически от
`REST_RADIUS_UNITS = 44` до `0.9·max(w,h)·zoom`; центр диска плавно идёт от
низа (экспозиция 24 units) к середине viewport. Нижняя навигация остаётся
рабочей. `reduced_motion` — мгновенная фиксация без анимации.

Context Light живёт на куполе: метка, кольцо внимания по ободу, пульс
активности, шкала количества вдоль открытого обода (слева направо, токен
Border).

## 3. Эшелоны и семантический зум

- **E1** — универсальные возможности (capabilities): Поиск, Sai, Задачи,
  Приложения, Входящие, Пространства, Устройства, Я. Порядок закреплён.
- **E2+** — дочерние кластеры; открываются зумом, как на карте.
- Порог детали `depth_threshold(d) = 1.15·1.9^(d-2)`; `detail()` —
  smoothstep(0.78t..t), т.е. объекты проявляются, а не появляются скачком.
- Диапазон зума 0.55–3.2. Эшелон — не страница и не подменю.

## 4. Стабильная пространственная память

Контекст меняет **заметность**, но никогда **позицию**. Позиции — в
географии (`Geography`), сохраняются в
`/data/saaios/var/orb-geography.json` (атомарно, tmp+rename; значения
квантованы до 1e-9 рад ради точного JSON-roundtrip).

Размещение: филлотаксис `dist = scale·sqrt(slot+0.5)`,
`bearing = start + slot·GOLDEN_ANGLE`; `E1_SCALE = 8°`, `DEPTH_FACTOR = 0.3`;
начальный азимут кластера и эфемерные места — от закреплённого FNV-1a.

Четыре яруса:

| Ярус | Смысл | Место |
|------|-------|-------|
| Persistent | постоянная география | сохраняется |
| Contextual | меняют заметность по контексту | сохраняется |
| Suggestion | временные подсказки (напр. задачи, ≤6) | эфемерное, не сохраняется |
| Availability | существует ≠ доступно | призрак (ghost), не удаляется |

Заметность: `Irrelevant < Deeper < Nearby < Now` (alpha по ступеням).
«Сейчас» — Accent-контур; выбранный — Focus-кольцо.

## 5. Существование ≠ доступность

Недоступный объект остаётся на своём месте как полый/приглушённый
(`Unavailable::Missing` → ghost). Офлайн-сервис приглушает приложения и
пространства, но не убирает их.

## 6. Объекты и примитивы

Каталог классов (17 + `Unknown(String)`) отображается в четыре
универсальных примитива: Disc, Square, Diamond, Ring. Неизвестный класс
получает примитив по умолчанию — Orb не требует знать тип заранее.

## 7. Поиск как направление и маршрут

Поиск локален: AND по токенам, Unicode-регистр, оценка по label/keyword.
Результат — не только «открыть», но и **направление и путь**: `Route`
(цель, откуда/куда, zoom_from/zoom_to с «нырком» зума, длительность
0.3–1.2 с по расстоянию).

В шелле: capability «Поиск» открывает поле над сферой (сфера остаётся
поднятой и занимает то, что оставили поле, строки результатов и
клавиатура). Строка результата — метка и «СВ · 42°» (направление и
расстояние от камеры). Набор текста **ничего не двигает**; на цель
указывает след по сфере. Первый выбор (тап по строке, Enter) — полёт по
маршруту (след укорачивается по мере прибытия); второй — открытие.
Кластер, недоступный или «вспоминаемый» объект показываются, но не
форсируются. Пустой запрос показывает весь список в порядке чтения (`browse`)
— это и есть списочная альтернатива жесту.

Экранная и USB-клавиатура набирают только латиницу, поэтому каждое
кириллическое имя (приложения, пространства, задачи, устройства) получает
латинское написание ключевым словом.

## 8. Ввод, не зависящий от устройства

Свайп = колесо = стик = трекпад = физическое колесо. Единый `NavInput` →
`Motion`. Нотч колеса 32 units, стик 300 units/s с мёртвой зоной 0.15,
нотч зума ×1.12. Инерция — `Inertia`. Касание: tap-slop 10 units,
tap ≤ 0.45 с, окно скорости 100 мс, pinch из двух указателей. Tap по
объекту: «нырок» (если эшелон ещё не раскрыт) либо активация.

Подключено: касание, колесо и перетаскивание мышью (`wl_pointer` — только
для сферы), клавиатура (↑↓←→ — кольцо фокуса, а если там ничего нет, сдвиг
вида; Enter — нырок/открытие; `+`/`−` — масштаб; `/` — поиск; Delete —
забыть призрак; Esc — опустить; Super — поднять/опустить). Логика стика
есть, чтения осей геймпада в шелле нет (нужен контроллер).

## 9. Глубина

Проекция, а не буквальный 3D: ортографическая, `facing = cos c`, камера-
«поворотный стол», широта ограничена 75°. Объекты на дальней стороне
затухают; порядок рисования — от дальних к ближним. Сетка (граду-
сник) 15° как ориентир, opaque-first: без blur и glow.

## 10. Спокойный UI

Четыре уровня внимания: сейчас / рядом / глубже / не важно. Нет потока
уведомлений в пространстве; задачи — эфемерные подсказки с лимитом.
Пустые состояния честные: ничего не рисуется «для вида».

## 11. Движение объясняет геометрию

Подъём, зум и маршрут — непрерывные траектории; нет телепортов. При потере
из виду (`is_lost`) сфера плавно возвращает камеру к ближайшему якорю
(`settle_if_lost`).

## 12. Доступность

Альтернативы жесту: `outline()`/`browse()` — список в порядке чтения с
направлением и расстоянием (пустой запрос в поиске); `step_focus()` —
направленный шаг фокуса (клавиатура). Скринридера в шелле нет.

## 13. Сценарии A–E

Сквозные тесты в `orb_space`: (A) покой → подъём → capability; (B) зум
проявляет E2, тап открывает; (C) поиск находит то, что вне вида, показывает
путь, летит и открывает; (D) офлайн-сервисы приглушают, не двигая; (E)
неизвестный класс — полноценный объект (виден, ищется, выбирается).

## 14. Забыть и производительность

Призрак (объект, который помнят, но не видят) убирается только явно:
выбрать его — рядом с точкой появляется чип «Забыть «…»» (или Delete).
Это единственный способ освободить место в географии.

Когда сфера полностью непрозрачна над окном страницы (подъём ≥ 0.85),
страница не рисуется — рисуется только нижняя навигация; результат
побитово совпадает с полной отрисовкой (тест). Выигрыш по кадрам не
измерен.

## 15. Границы реализации v1

Не сделано: чтение осей геймпада, масштаб колесом мыши (нет модификаторов),
прокрутка списка пальцем. Проверка на железе — в самом конце очереди
(ORB-HW).
