# Sprint 20 — Bluetooth: сопряжение устройств

## Паспорт

- Состояние: `Done (обнаружение подтверждено; сопряжение не
  тестировалось)` (2026-09-13). Часть серии S14-S25 (см. S14).
- Зависит от: S13 (`Done`, с честными оговорками), S19 (тот же
  архитектурный паттерн и `draw_row_list`).

## Goal

Реальное обнаружение/сопряжение через уже built-ные, но никогда не
подключённые `/saaios/bt-scan`/`/saaios/bt-pair` (raw Bluetooth
Management Socket), а не через новый демон или предположение об
отсутствующей инфраструктуре.

## Scope

Входит: карточка "Bluetooth" на "Я", экран "Bluetooth устройства"
(поиск ~8с в фоне, список найденных, сопряжение по тапу, статус
сопряжения).

Не входит (честно, см. ADR-066): `bt-gatt-probe` (BLE GATT-
инспекция, не запрашивалась); `bt-pair --restore` при загрузке
(ранее сопряжённые устройства не переподключаются автоматически
после перезагрузки).

Device: подтверждено физически 2026-09-13 -- экран "Bluetooth
