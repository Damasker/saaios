  VoLTE не заявлено. 12d: запрос `0x0712` ответил `error_raw=6`,
  экстренный вызов не делался и не заявлен. 12e и 12f не

- Опкоды и тела берутся только из уже восстановленных стоковых
  сборщиков. Пустой пункт не начинается.

## Что уже восстановлено

В owner, без новой отправки:

| Услуга | Сборщик | Что уже на строке |
|---|---|---|
| Голос | набор `0x0001`, список `0x0000`, сброс `0x0008` | «голос» — регистрация, не вызов |
| SMS | отправка `0x0100` (271 байт), активация `0x0107`, рассылка `0x0106`, SMSC | одна отправка принята; активация и рассылка остаются принятием кадра |
| IMS / VoLTE | профиль `ims`; чтение `0x0938` | профиль `error_raw=2`, чтение `error_raw=22` |
| Экстренный | профиль `sos`; запрос `0x0712` (14 байт, без номера) | профиль `error_raw=2`, запрос `error_raw=6` |
| Точка доступа | профили `internet`, `ims`, `sos` | в строке только эти три имени |
| Оператор | режим выбора уже в строке («авто») | список сетей не публикуется |

Набор в owner есть. Номер в лог не попадает.

### 12a на этой загрузке

Файл номера был на месте до старта camp: `camp_call_number=armed len=13`.
Один набор: `camp_call dial response=yes error_raw=0`. Затем опрос
списка и один сброс: `camp_call hangup response=yes error_raw=0`.
Номер, индекс и список не публикуются. `bearer=rmnet1`, `ipv4=yes`.
Файл номера после попытки удалён, следующий старт camp его не прочитает.

### 12b на этой загрузке

`ProtocolSmsBuilder::BuildSendSms` даёт кадр `0x0100` длиной 271.
Пустой SMSC записан так, как библиотека пишет его при отсутствии
строки центра: байт длины 1 и нулевой следующий байт. Текст уходит
внутри TPDU, в лог не попадает. Файл назначения был на месте до
старта camp: `camp_sms_number=armed len=13`. Одна отправка:
`camp_sms=sent step=send`, затем
`camp_sms response=yes error_raw=0`. Номер и текст не публикуются.
`modem_state=ONLINE`, `bearer=rmnet1`, `ipv4=yes`. Файл после
попытки удалён, следующий старт camp его не прочитает.

### 12c…12f на этой загрузке

Шаги не начинались.

- 12c. Профиль `ims` по-прежнему одна строка с `error_raw=2`,
  повторно не шлётся. Отдельное чтение
  `BuildGetVoLteProvisionUpdate` (`0x0938`, длина 12) на этой
  загрузке: `camp_volteprov response=yes error_raw=22`. Байт
  статуса при ненулевом коде не публикуется. Кадр «обновление
  закончено» (`0x0939`) не отправлялся. VoLTE не заявляется.
- 12d. `camp_sos`: одна строка, `error_raw=2`. Повторной отправки нет.
  Отдельный запрос `QueryEmergencyCallAvailableRadioTech`
  (`0x0712`, длина 14, без номера) на этой загрузке:
  `camp_emquery response=yes error_raw=6`. Тело ответа не
  публикуется. Набора не было. Экстренный вызов не заявляется.
  `bearer=rmnet1`, `ipv4=yes`.
- 12e. Новое тело профиля не выдумывается. В строке остаются уже
  поданные `internet`, `ims` и `sos`.
- 12f. Новый SET выбора сети не шлётся. В строке остаётся «авто».
  Список сетей не публикуется.

`bearer=rmnet1`, `ipv4=yes`.

## Шаги

Один шаг за раз. Телефонный шаг начинается только если сборщик уже
в дереве и на загрузке есть строка `error_raw=0`. Ноль строк или
поздний другой код — слово пустое, шаг не начинается. `ims` и `sos`
повторно не шлются.

| Шаг | Результат | Ворота |
|---|---|---|
| 12a | Один голосовой набор и сброс | Сборщики `0x0001` / `0x0008` уже в owner. Номер задаёт отдельный запуск. В лог — `camp_call dial response=yes error_raw=`. Номер, индекс и список не публикуются |
| 12b | Одна передача SMS | Сборщик `0x0100`, длина 271, уже в owner. Назначение задаёт отдельный запуск. В лог — `camp_sms response=yes error_raw=`. Номер и текст не публикуются. `smsact` / `smscb` службой не становятся |
| 12c | IMS / VoLTE | Профиль `ims` остаётся с `error_raw=2`. Чтение `0x0938` ответило `error_raw=22`. Кадр `0x0939` не шлётся. VoLTE не заявляется |
| 12d | Экстренный вызов | Профиль `sos` остаётся с `error_raw=2`. Запрос `0x0712` ответил `error_raw=6`. Набора не было. Экстренный вызов не заявляется |
| 12e | Редактор точки доступа | Меняются только уже поданные `internet`, `ims`, `sos`. Новый текст профиля и новое тело кадра не выдумываются |
| 12f | Выбор оператора | В строке остаётся уже показанный режим «авто». Ручной список сетей не публикуется. Новый SET не шлётся |

Доказательство телефонного шага — та же четвёрка, что в MODEM-11:
status, кэш, «Наблюдения», строка, плюс живые `bearer=rmnet1` и
`ipv4=yes`. Голос, SMS, IMS и экстренный вызов называются только
после своего `error_raw=0`.
