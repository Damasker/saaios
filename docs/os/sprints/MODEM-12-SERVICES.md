# MODEM-12 — услуги после живого канала

## Паспорт

- Состояние: **Planned**. MODEM-00…11 закрыты. На этой загрузке
  `bearer=rmnet1`, `ipv4=yes`, camp 564 держит прежний образ.
- Зависит от: MODEM-11. Новых кадров этот паспорт не отправляет.
- Опкоды и тела берутся только из уже восстановленных стоковых
  сборщиков. Пустой пункт не начинается.

## Что уже восстановлено

В owner, без новой отправки:

| Услуга | Сборщик | Что уже на строке |
|---|---|---|
| Голос | набор `0x0001`, список `0x0000`, сброс `0x0008` | «голос» — регистрация, не вызов |
| SMS | `0x0107` активация, `0x0106` рассылка, SMSC | принятие кадра, не передача сообщения |
| IMS / VoLTE | профиль `ims` | на этой загрузке `error_raw=2` |
| Экстренный | профиль `sos` | на этой загрузке `error_raw=2` |
| Точка доступа | профили `internet`, `ims`, `sos` | в строке только эти три имени |
| Оператор | режим выбора уже в строке («авто») | список сетей не публикуется |

Набор в owner есть. На этой загрузке вызов не ставится: номер в
кадр пишет только явный шаг 12a, и номер в лог не попадает.

## Шаги

Один шаг за раз. Телефонный шаг начинается только если сборщик уже
в дереве и на загрузке есть строка `error_raw=0`. Ноль строк или
поздний другой код — слово пустое, шаг не начинается. `ims` и `sos`
повторно не шлются.

| Шаг | Результат | Ворота |
|---|---|---|
| 12a | Один голосовой набор и сброс | Сборщики `0x0001` / `0x0008` уже в owner. Номер задаёт отдельный запуск. В лог — `camp_call dial response=yes error_raw=`. Номер, индекс и список не публикуются |
| 12b | Передача SMS | Отдельного сборщика отправки в дереве нет. Пока его нет, шаг не начинается. `smsact` / `smscb` службой не становятся |
| 12c | IMS / VoLTE | Профиль `ims` остаётся с `error_raw=2`. Повторной отправки нет. VoLTE не заявляется |
| 12d | Экстренный вызов | Профиль `sos` остаётся с `error_raw=2`. Повторной отправки нет. Экстренный вызов не заявляется |
| 12e | Редактор точки доступа | Меняются только уже поданные `internet`, `ims`, `sos`. Новый текст профиля и новое тело кадра не выдумываются |
| 12f | Выбор оператора | В строке остаётся уже показанный режим «авто». Ручной список сетей не публикуется. Новый SET не шлётся |

Доказательство телефонного шага — та же четвёрка, что в MODEM-11:
status, кэш, «Наблюдения», строка, плюс живые `bearer=rmnet1` и
`ipv4=yes`. Голос, SMS, IMS и экстренный вызов называются только
после своего `error_raw=0`.

## Вне программы

Эти три пункта спринта не получают.

- Прошивка модема остаётся тем образом, который уже в RAM слота B.
- Службой конечной точки остаётся `saai-modemd`. Штатные `cbd`,
  `rild` и `rfsd` постоянными процессами не запускаются.
- Цель остаётся лично принадлежащий Pixel 7 panther.

## Приёмка

- 12a…12f либо доказаны на живом канале, либо в этом файле записано,
  что ворота закрыты и шаг не начинался.
- Прошивка, штатные `cbd`/`rild`/`rfsd` и модем не-panther в
  программу не входили.
