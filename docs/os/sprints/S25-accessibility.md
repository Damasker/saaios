# Sprint 25 — Доступность (размер шрифта, контраст)

## Паспорт

- Состояние: `Реализовано, проверка отложена` (2026-09-13). Последний
  спринт серии S14-S25 (см. S14).
- Зависит от: S13 (`Done`, с честными оговорками).

## Goal

Размер текста и контраст как настройки на "Я", без переписывания
десятков существующих вызовов отрисовки и без ещё одной смены
гарнитуры (тема шрифта закрыта в S13).

## Scope

Входит: `render::set_text_scale`/`apply_contrast_boost`, карточки
"Размер текста"/"Контраст" на "Я".

Не входит (честно, см. ADR-069): per-элементная цветовая палитра
(вместо неё -- глобальный пост-процесс-стретч); смена шрифта.

## Test

для `apply_contrast_boost`), `cargo clippy -p saai-shell` чист,
кросс-компиляция под `pixel7` профиль чиста.

Device: отложено, но с особым вниманием -- значения по умолчанию
