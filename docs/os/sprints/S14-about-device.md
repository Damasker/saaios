# Sprint 14 — «О телефоне»

## Паспорт

- Состояние: `In progress` (2026-09-13). Часть серии S14-S25 --
  пользователь запросил полный, продуманный набор системных функций
  единым проходом; по явному указанию пользователя (`/goal`)
  физическая проверка на устройстве отложена и выполняется одним
  финальным шагом после реализации всех спринтов серии, а не после
  каждого Change по отдельности, как во всех предыдущих спринтах
  этого проекта. Это единственное отступление от стандартного
  Definition of Process в этой серии -- явно санкционировано
  пользователем.
- Зависит от: S13 (`Done`).

## Goal

Вкладка "Я" показывает реальные номер сборки, версию ядра, модель
устройства и время работы -- ранее в проекте не существовало ни
одного из этих полей нигде.

## Scope

- Входит: build id (короткий git-хеш, вживлён в бинарь на этапе
  сборки), модель устройства, версия ядра, аптайм -- новая карточка
  на "Я", сразу после сводки пространств.
- Не входит: переиспользование `crates/system-tools`'s
  `system_identity()` -- сознательно, крейт тянет `tokio`/
  `async_trait`/`tool_registry`, неприемлемо тяжело для
  `panic_immediate_abort`-бинаря ради трёх строк на одном экране.

## Change

1. `build.rs`: `git rev-parse --short=12 HEAD` → `cargo:rustc-env=
   SAAIOS_BUILD_ID`, `"unknown"` при отсутствии git. Отслеживает
   `.git/logs/HEAD` (не `.git/HEAD` -- тот меняется только при
   checkout, не при обычном commit).
2. `kernel_release()`/`hardware_model()`/`uptime_string()` -- три
   прямых чтения `/proc` без промежуточных крейтов.
3. `me_content_cards()`: новая вторая карточка "SaaiOS · сборка
   <hash>" со статусом "<модель> · ядро <release> · работает
   <аптайм>".
