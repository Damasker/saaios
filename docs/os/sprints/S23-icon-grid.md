# Sprint 23 — Сетка/иконки на главном экране

## Паспорт

- Состояние: `Done (иконки-плейсхолдеры)` (2026-09-13). Часть серии
  S14-S25 (см. S14). Физически подтверждено: сетка из 3 колонок
  видна на "Сейчас", текст читаем (см. также ADR-070's исправление
  шрифтового пайплайна, обнаруженное на этой же проверке).
- Зависит от: S13 (`Done`, с честными оговорками) -- отложенный
  пункт визуального прохода (ADR-057).

## Goal

"Сейчас" (app launcher) переходит на сетку из иконок, как на
телефоне, вместо одноколоночного списка карточек. Остальные три
вкладки (текстовые по своей природе) остаются списком.

## Scope

Входит: `now_grid_rect` (3 колонки), `render::draw_root`'s `is_grid`
ветка рисования (квадрат-плейсхолдер с первой буквой + подпись под
ним, без описания/кнопки).

Не входит (честно, см. ADR-067): реальные иконки приложений -- в
проекте нет пайплайна ассетов ни для одного приложения. Плейсхолдер
-- цветной квадрат с первой буквой имени.

## Test

Host: `cargo test -p saai-shell` (28/28 ok, включая
`now_grid_rect_lays_out_three_columns_per_row`), `cargo clippy -p
saai-shell` чист, кросс-компиляция под `pixel7` профиль чиста.

Device: подтверждено физически 2026-09-13 -- сетка визуально
отличается от списка, текст рендерится (ADR-070).
