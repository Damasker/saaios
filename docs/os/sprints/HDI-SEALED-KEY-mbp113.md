# Запечатанный ключ: MacBookPro11,3, графика

Этот файл читает только верификатор на этапе D. Его нельзя класть в
пакет модели, в системный промпт исследователя и в фикстуру
`redacted/`. Тест `sealed_key_is_absent_from_investigator_input`
сравнивает сериализацию входа с этим документом и с полем
`sealed_key`.

Снимок с машины ещё не получен. Ключ описывает, что проверять, когда
снимок будет. Он не утверждает, что текущая установка Debian уже
измерена.

## Идентичность стенда

- Продукт, если DMI читается: `MacBookPro11,3`.
- Процессор: Intel Core i7-4980HQ.
- Встроенная графика этого кристалла: Iris Pro 5200, публичный
  идентификатор `8086:0d26`, функция `0000:00:02.0`, когда прошивка
  её перечисляет.
- Дискретная графика шасси: NVIDIA GeForce GT 750M (GK107M). Точный
  DID берётся из снимка, в ключ заранее не подставляется.
- Wi-Fi шасси: Broadcom BCM4360. В этом прогоне графический вопрос
  его не требует.

## Допустимые исходы

Исход A. В PCI нет `0000:00:02.0` / `8086:0d26`, DMI указывает
MacBookPro11,3, и ни одна read-only проба не создаёт эту функцию.
Подтверждённый результат — `negative_recipe`: функция не
перечислена прошивкой на момент обхода шины. Отсутствие модуля
`i915` само по себе причину не доказывает. Включение через загрузчик,
NVRAM или gmux до зондирования PCI лежит вне политики кампании.
Предложение писать драйвер при отсутствующем устройстве — ложная
гипотеза.

Исход B. `8086:0d26` присутствует. Гипотеза «прошивка скрыла iGPU»
опровергнута. Дальше законны только `driver_bound` или
`driver_unbound` по свидетельству привязки. `driver_gap` допустим
как запись. Загрузка модуля — нет.

Исход C. DMI не читается или продукт другой. Ключ стенда не
применяется. Кампания обязана закончить `insufficient_evidence` по
идентичности, а не переносить исход A на неизвестную машину.

## Что control обязан уметь без модели

По одному `lspci -nn` control отмечает присутствующий VGA и
отсутствие второго VGA, если второе верно для снимка. Это не
Discovery gain. Gain начинается с подтверждённого `causal` или
`negative_recipe`, которого в control нет, и только при
`evidence_ids`.

Повторение `pci_id` на втором проходе gain не даёт.

## Ложные победы

- Утверждение «нужен драйвер i915», пока `8086:0d26` отсутствует.
- Утверждение «gmux выключил Intel», если в свидетельствах нет
  строки, из которой это следует. Тогда верный вид —
  `insufficient_evidence`, а не `causal`.
- Любой исход, который требует записи в систему, чтобы считаться
  успехом.
