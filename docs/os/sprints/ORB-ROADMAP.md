# ORB roadmap — пространственная навигация

Спецификация: [orb-spec-v1](../ui/orb-spec-v1.md). Решение:
[ADR-430](../../adr/ADR-430-orb-spatial-navigation.md).

Правило: сначала код и host-тесты; проверка на железе — в конце очереди.

| ID | Содержание | Состояние |
|----|------------|-----------|
| ORB-01 | Чистый crate `saai-orb`: геометрия, камера, география, компоновка, ввод, жесты, поиск/маршрут, доступность (68 тестов) | Done (host) |
| ORB-02 | Шелл: покой/подъём/pan/zoom/dive/активация, реальные объекты, сохранение географии, отрисовка, Context Light на куполе | Done (host) |
| ORB-03 | Поле поиска в шелле и отрисовка следа маршрута (`Route::trail`) | Pending |
| ORB-04 | Доступность в шелле: фокус с клавиатуры (`step_focus`), список `outline`, колесо/стик/трекпад в `NavInput` | Pending |
| ORB-05 | Жест «забыть» устаревшего призрака; пропуск отрисовки страницы под непрозрачной сферой (перф) | Pending |
| ORB-HW | Проверка на панели: `df -Bk`, контраст и размер купола и шкалы, ощущение pull/pan/pinch, частота кадров, перекрытие нижнего контента, цели касания | End of queue |

## Evidence (ORB-01/02)

`cargo test -p saai-orb -p saai-shell`, `cargo clippy` без предупреждений
в затронутых crate; визуальный дамп состояний (покой, полуподъём, открыт,
отдалён, нырок в Приложения) просмотрен на host.
