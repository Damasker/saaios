# Sprint 24 — PIN/защита экрана блокировки

## Паспорт

- Состояние: `Реализовано, проверка отложена (приоритетная -- меняет
  путь разблокировки)` (2026-09-13). Часть серии S14-S25 (см. S14).
- Зависит от: S04 (`Done`) -- session-lock/lock-surface архитектура
  (ADR-016).

## Goal

Опциональный PIN на замену безусловного tap-to-unlock, без изменения
поведения по умолчанию для уже существующих настроек.

## Scope

Входит: `ShellSettings.pin_code` (опционально), цифровая клавиатура
(`pin_keypad_rect`), "Изменить PIN"/"Убрать PIN" на "Я", ввод PIN на
самом lock-surface с автоматической проверкой по длине.

Не входит (честно, см. ADR-068): восстановление забытого PIN без
serial console; лимит попыток/таймаут после неверных вводов.

## Test

Host: `cargo test -p saai-shell` (30/30 ok, включая
`pin_keypad_action_at_*`/`pin_setup_action_at_*`), `cargo clippy -p
saai-shell` чист, кросс-компиляция под `pixel7` профиль чиста.

Device: отложено, но приоритетно при финальном проходе -- это
единственный спринт серии, трогающий путь разблокировки. С
`pin_code: None` (по умолчанию) поведение должно быть неотличимо от
уже подтверждённого tap-to-unlock.
