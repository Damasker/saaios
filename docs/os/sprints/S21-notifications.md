# Sprint 21 — Уведомления

## Паспорт

- Состояние: `Реализовано, проверка отложена` (2026-09-13). Часть
  серии S14-S25 (см. S14).
- Зависит от: S06 (entity store), S09 (задачи, entity-модель),
  S13 Change 2 ("Входящие").

## Goal

"Входящие" показывает не только задачи, но и обобщённые системные
уведомления; первый реальный продюсер -- предупреждение о низком
заряде батареи.

## Scope

Входит: `saaios.notification` entity type, объединённый список в
"Входящих", dismiss тапом, low-battery продюсер (клиентский, без
нового сервиса).
Не входит: push-доставка, уведомления от сторонних приложений, OTA-
уведомление (это S22).

## Test

Host: 24/24 теста, clippy и кросс-компиляция чисты. Device: отложено.

## Rollback
