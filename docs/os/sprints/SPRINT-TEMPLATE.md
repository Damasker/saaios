# Sprint NN — название результата

## Паспорт

- Состояние: `Backlog | Ready | In progress | Verify | Done | Blocked`
- Зависит от:
- Архитектурные решения:
- Рабочий fallback:

## Goal

Один наблюдаемый пользовательский или платформенный результат.

## Current state

Проверенные факты до изменения.

## Scope

- входит;
- не входит.

## Change

Малые вертикальные задачи в порядке выполнения.

## Test

- unit/protocol;
- host integration;
- fault injection;
- image inspection;
- device/physical/cold reboot — если применимо.

## Acceptance criteria

Измеримые утверждения без слов «работает нормально» и «почти готово».

## Threat / privacy impact

Новые данные, полномочия, каналы и негативные тесты.

## Rollback

Точный предыдущий artifact и способ возврата.

## Evidence

Заполняется при закрытии: commit, test log, image SHA-256, binary hash,
физическое подтверждение и известные ограничения.
