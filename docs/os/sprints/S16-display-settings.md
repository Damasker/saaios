# Sprint 16 — Экран: яркость и таймауты

## Паспорт

- Состояние: `Реализовано, проверка отложена` (2026-09-13). Часть
  серии S14-S25 (см. S14 для объяснения отложенной проверки).
- Зависит от: S13 (`Done`), S11 (ADR-040/041/042 -- deep idle).

## Goal

"Я" позволяет менять яркость экрана и оба таймаута (блокировка/
гашение), значения сохраняются между перезапусками.

## Scope

Входит: тап-по-циклу яркость (25/50/75/100%), блокировка
(30/60/120/300с), гашение (15/60/300/900с), персистентность в JSON.
Не входит: drag-слайдер, авто-яркость по датчику освещённости.

## Test

Host: тесты/clippy/кросс-компиляция чисты. Device: отложено.

## Rollback

Предыдущий физически подтверждённый `saai-shell` (`cp && mv`).
Настройки живут в отдельном файле на `/data` -- откат бинаря не
трогает уже сохранённые значения (не проблема: формат обратно
совместим, старые поля просто продолжат читаться).
